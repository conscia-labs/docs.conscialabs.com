---
title: Create and manage groups
description: Use groups to apply Gateway governance to multiple people.
---

Groups collect organization members so that the same governance can apply to them. A group can have Model Access, Allowance, and Request Restrictions policies.

## Create a group

1. Open **Organization Administration → Groups**.
2. Select **Add group**.
3. Enter a name and, optionally, a description.
4. Add active organization members.
5. Assign policies from the group or Policies page.

Add people who share an access need or operational responsibility. A person can belong to more than one group. Group policies contribute to that person's effective governance together with organization and direct policies.

## Understand group allowances

A group Allowance contributes to each member's effective allowance. It is not a shared pool for the group. Review usage on each person's Usage and allowance view.

When a person belongs to several groups, an explicitly selected primary allowance group takes precedence. Without one, the most restrictive applicable group allowance is used. A direct person allowance takes precedence over group allowances, and the organization default applies when no more specific allowance exists.

## Archive a group

Archive a group when it should stop contributing governance. An archived group cannot receive new members or policy assignments. Its history remains available.
